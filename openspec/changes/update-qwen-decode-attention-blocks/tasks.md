# Tasks

ID（G0P・G0F・G0U・G1I・G1F・G1R・G0K・G1K）の定義は design.md の「検証 ID と成果物の対応」を参照する。「基点」は、この変更の候補が `kvarn-kv-cache-quantization` 上で分岐したリビジョンで、比較の対照はすべて基点のカーネルまたは基点のビルドとする（`main` と `upstream/main` は KVarN を含まないため使わない）。数分を超える測定は切り離したプロセスで起動し、1 本のテストの見積もりを 1 時間以内とし、見積もりの 2 倍で自動停止する（変更 `add-kvarn-kv-cache-quantization` の D16・D22・D23）。GPU を使う測定は、他の GPU ジョブや、変更 `update-qwen38-flash-next-decode-attention-blocks` の測定と時間を重ねない。ゲートに届かない時点で作業を止め、測定値・原因の分析・選択肢を利用者に返す（design D9）。採用の判定までは基点の旧カーネルが既定で、採用した段階だけが旧カーネルを削除する。
