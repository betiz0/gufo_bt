# Tasks

ID（T-01〜T-09、G0〜G4）の定義は design.md の「検証 ID と成果物の対応」を参照する。数分を超える測定・スイートは design D16 の実行方法（切り離したプロセス、完了マーカーの待機、単位ごとの成果物と再開）で行い、対話ツールの 1 回の呼び出しの中で完了を待たない。

2026-10-08 以後のテストは design D23 に従う。テストは `tools/qwen27b/ledger_run.py` で 1 本ずつ実行し（D22）、1 本の見積もりは 1 時間以内とする（超える場合は分割または縮小）。実行時間が見積もりの 2 倍に達したら、ハーネスの PID だけを自動停止して OUT を記録する。Qwen3.8 27B にチャット形式で生成させるテストと測定（`serve llm` への要求、`gufo prompt`・`chat`）では、`reasoning_effort: low`（CLI では `--reasoning-effort low`）を指定する。品質ハーネスと `gufo bench` はチャットテンプレートを通さないため対象外。残りの作業の順は、8（利用開始）→ 6.1〜6.4 → 5.7 → 6.6 とする。
