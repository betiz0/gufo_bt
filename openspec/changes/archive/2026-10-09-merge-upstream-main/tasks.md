# Tasks

VRAM と GPU を使うテストは並列実行しない。`ctest` に `-j`／`--parallel` を付けず、複数の GPU テストを同時に起動せず、GPU を使うサーバやベンチと同時に走らせない（`ctest` の既定は直列）。CPU のみのテストは並列でよい。数分を超える実行は `tools/qwen27b/ledger_run.py run` で 1 本ずつ前面のコマンドとして起動し（design D9。アーカイブ済み変更の D22・D23）、`--id`・`--task`・`--purpose`・`--estimate-seconds`・`--estimate-basis`・`--pass-criteria` を指定する。見積もりは 1 時間以内に分割し、2 倍に達したら `ledger_run.py` の自動停止に任せ、完了は `status`／`wait` かログの単発確認で待つ（ポーリングループは使わない）。ハーネスのラベルは実行ごと・ビルドごとに新しくし（`merge-upstream-` で始める）、既存のラベルを再利用しない。KVarN の構成は `kvarn-k4v4` + `--kv-cache-tail 512` と `kvarn-k6v5` + `--kv-cache-tail 2048`、文脈長（深度）は 256 と 131,072 に絞る。マージ後のビルドは `build/gpu-test-nix`（Nix）を使い、`build/gpu-test`（hipcc）はマージ前の参照ビルドとして残す。以下の ctest は `nix develop -c ctest --test-dir build/gpu-test-nix -LE multi-session -R '<regex>' --output-on-failure` の形で実行する。
